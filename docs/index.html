Questions

Do these extensions include or replace Ansys?

No. Each extension registers the corresponding Ansys-maintained open-source MCP server. Ansys software, licensing and upstream Python requirements remain separate.

What does MCP add to VS Code?

The Model Context Protocol gives Copilot Chat a standard way to discover and call tools exposed by local engineering applications. VS Code starts the selected server when requested.

Do I need an Ansys license to install the extension?

You can install the extension without one. Live solver operations require the appropriate Ansys product and license. Some server capabilities may work without launching a solver.
