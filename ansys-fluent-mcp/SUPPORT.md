# Support

For connection issues with the extension, first check that VS Code supports MCP, Git is installed, and `uvx` is available in PATH. See the [Ansys PyFluent MCP documentation](https://github.com/ansys/pyfluent-mcp) for Python, Fluent installation, license, and server requirements.

The upstream MCP server is maintained by Ansys. This independent connector is maintained under the OutBlade publisher identity.
